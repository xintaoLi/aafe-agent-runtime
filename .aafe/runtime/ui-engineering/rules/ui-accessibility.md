# UI Accessibility Rules

UI-A11Y-001

WCAG 2.2 AA is P0. Perceivable, Operable, Understandable, Robust.

UI-A11Y-002

Use semantic HTML before ARIA.

UI-A11Y-003

Name, role and value MUST be available to assistive technology.

UI-A11Y-004

Contrast meets 4.5:1 for text (3:1 for large text and UI components).

UI-A11Y-005

Touch targets meet 44×44 CSS px on coarse pointers (WCAG 2.2 target size).

UI-A11Y-006

Errors are identified in text, linked to fields, and focus moves to the first error.

UI-A11Y-007

Motion respects prefers-reduced-motion.

UI-A11Y-008

Status messages use a live region or equivalent, not color flash alone.
