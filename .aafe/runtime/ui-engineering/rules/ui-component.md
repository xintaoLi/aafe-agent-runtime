# UI Component Rules

UI-COMP-001

Reuse existing components. Duplicating a project primitive is a defect.

UI-COMP-002

Prefer an existing variant over new CSS.

UI-COMP-003

Selecting a component requires a decision tree (count, search, multi, async, mobile, keyboard).

UI-COMP-004

Every interactive component MUST be operable by keyboard.

UI-COMP-005

Dialog MUST have an accessible title, focus trap, Esc and focus restore.

UI-COMP-006

Component APIs name user intent (variant, size, invalid), not internals.

UI-COMP-007

No component enters implementation without a state list.

UI-COMP-008

Icon-only controls MUST have an accessible name.
