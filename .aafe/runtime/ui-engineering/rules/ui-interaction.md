# UI Interaction Rules

UI-INT-001

Mouse + keyboard + screen reader are one interaction, not three optional layers.

UI-INT-002

Click, focus, keyboard, selection, shortcut and context menu MUST be designed together for interactive surfaces.

UI-INT-003

Drag/drop MUST have a keyboard alternative.

UI-INT-004

Hover MUST NOT be the only way to reveal an action.

UI-INT-005

Focus order follows reading and task order.

UI-INT-006

Shortcuts MUST be documented and must not trap focus.
