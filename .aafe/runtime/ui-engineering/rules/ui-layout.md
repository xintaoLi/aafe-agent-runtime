# UI Layout Rules

UI-LAY-001

Layout follows information architecture, not a leftover 12-column habit.

UI-LAY-002

Primary task and primary action occupy the highest-affordance region.

UI-LAY-003

Secondary information may be hidden behind progressive disclosure.

UI-LAY-004

Do not wrap every block in a Card. Card is a grouping device, not a default skin.

UI-LAY-005

Page composition is Page → regions → existing primitives, never a one-off organism.

UI-LAY-006

Desktop / tablet / mobile are different navigation strategies, not a single column dump.
