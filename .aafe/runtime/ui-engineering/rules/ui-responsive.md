# UI Responsive Rules

UI-RESP-001

Responsive strategy covers container, grid, breakpoint, navigation, sidebar, table, form, dialog, drawer and interaction.

UI-RESP-002

Desktop: sidebar + content. Tablet: collapsible sidebar. Mobile: bottom nav or drawer. Not `width < 768 → column`.

UI-RESP-003

Tables may become stacked rows or cards; they must remain comparable.

UI-RESP-004

Dialog MAY become Drawer on small screens; focus trap still applies.

UI-RESP-005

Do not remove keyboard operation on touch layouts.
