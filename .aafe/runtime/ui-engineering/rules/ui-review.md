# UI Review Rules

UI-REV-001

Every UI change exits through ui-review: UX, Visual, Code, A11y, Responsive, Performance.

UI-REV-002

Review output is a score, status (pass | needs_fix | fail) and issue list.

UI-REV-003

High accessibility issues fail the review.

UI-REV-004

Anti-slop defaults (gradient, glass, purple AI, card soup, giant hero) are medium+ issues unless the product language justifies them.

UI-REV-005

needs_fix MUST be repaired before the UI is treated as final.
