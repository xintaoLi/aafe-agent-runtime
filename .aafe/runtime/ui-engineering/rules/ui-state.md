# UI State Rules

UI-STATE-001

Every UI component MUST account for: default, hover, focus, active, selected, disabled, loading, error, success, empty, readonly, partial.

UI-STATE-002

Missing state design blocks implementation.

UI-STATE-003

Loading, empty and error are product states, not afterthought spinners.

UI-STATE-004

Table additionally requires sorting, filtering, pagination and virtualization decisions.

UI-STATE-005

Partial / indeterminate state MUST be distinguishable without color alone.

UI-STATE-006

Disabled controls remain perceivable and explain why when the user can reach them.
