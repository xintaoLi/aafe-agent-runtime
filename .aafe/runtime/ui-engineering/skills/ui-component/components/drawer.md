# Drawer

## Purpose

A side or bottom panel for secondary tasks that keep page context.

## When to use

- filters
- detail panes
- mobile navigation
- settings adjacent to a page

## When not to use

- blocking confirmations (Dialog)
- primary page content

## Anatomy

- title
- body
- actions
- close

## Variants

left, right, bottom

## Sizes

sm, md, lg

## States

closed, open, loading

## Accessibility

- title
- focus trap
- Esc
- focus restore
- swipe/close announced

## Anti-patterns

- Recreating this primitive when the project already has one
- Hardcoded colors instead of semantic tokens
- Hover-only interaction
