# Dropdown Menu

## Purpose

A compact list of actions anchored to a control.

## When to use

- overflow actions
- row menus
- account menus

## When not to use

- form value selection (Select)
- primary navigation

## Anatomy

- trigger
- menu
- item
- separator
- shortcut

## Variants

default, context

## Sizes

md

## States

closed, open, focus, disabled

## Accessibility

- menu/menuitem
- Arrow keys
- Esc
- typeahead

## Anti-patterns

- Recreating this primitive when the project already has one
- Hardcoded colors instead of semantic tokens
- Hover-only interaction
