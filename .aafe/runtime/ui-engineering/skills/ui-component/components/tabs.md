# Tabs

## Purpose

Switch between peer views of the same object at one URL level.

## When to use

- peer panels
- settings groups
- in-page views

## When not to use

- wizard steps (Stepper)
- primary app navigation
- SEO-distinct pages

## Anatomy

- tablist
- tab
- tabpanel

## Variants

line, enclosed

## Sizes

sm, md

## States

selected, focus, disabled, overflow

## Accessibility

- tab / tabpanel
- Arrow keys
- selected tab in tab order

## Anti-patterns

- Recreating this primitive when the project already has one
- Hardcoded colors instead of semantic tokens
- Hover-only interaction
