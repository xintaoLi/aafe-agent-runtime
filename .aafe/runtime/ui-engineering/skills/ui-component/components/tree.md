# Tree

## Purpose

Navigate or select hierarchical items.

## When to use

- file trees
- org trees
- nested permissions

## When not to use

- flat lists
- breadcrumbs
- cascading form values (Cascader)

## Anatomy

- tree
- item
- group
- expander

## Variants

navigation, multi-select

## Sizes

md

## States

collapsed, expanded, selected, focus, loading, disabled

## Accessibility

- tree / treeitem
- Arrow keys
- aria-expanded
- aria-selected

## Anti-patterns

- Recreating this primitive when the project already has one
- Hardcoded colors instead of semantic tokens
- Hover-only interaction
