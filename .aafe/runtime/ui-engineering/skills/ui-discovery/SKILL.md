# UI Discovery

## Purpose

Answer what this project already has before any UI is written.

## MustAsk

- 当前 UI Framework 是什么？
- 有没有 Design System？
- 有哪些已有组件？是否重复？
- 当前页面有什么 UI Pattern？
- 有没有 Token / Figma / Storybook？
- 有没有已有页面可以复用？

## Workflow

1. 项目扫描
2. UI 技术栈识别
3. Design System 识别
4. Component Registry 识别
5. Existing Pattern 识别
6. Token / Figma / Storybook 识别
7. 可复用页面识别
8. 再设计

## Forbidden

Do not write UI during discovery. Compose > Create.
