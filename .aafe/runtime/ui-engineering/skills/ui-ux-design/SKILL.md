# UX Design

## Purpose

Design from user and task, not from Button / Card / Input.

## Flow

User → Goal → Task → Information Architecture → User Flow → Interaction Model → Page Structure → Component → Visual Design

## MustAsk

- 用户要做什么？
- 最重要的任务是什么？操作频率？
- 什么信息应优先看到？什么操作应最容易触达？
- 什么可以隐藏？哪些状态必须明确反馈？
