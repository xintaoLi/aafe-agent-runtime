AAFE 配置

本机可视化写入 .aafe.config.json，覆盖工作流 / Agent / MCP / 提交 / TAPD / E2E。

工作流 Agent MCP 提交 TAPD E2E 预览

工作流模式

ask 每个门禁询问；autonomous 由模型判定，仅 Hard Ask 停下。

Agent mode

开启后，aafe run 把规划结果交给 Cursor SDK 执行。不影响 context / impact / plan。

有 API Key 时从 Cursor 拉取可用模型；否则显示内置选项。

MCP

只作用于 Cursor 执行步。默认不自动读取 .cursor/mcp.json，除非勾选 setting sources 或填写配置文件。

内联 servers，同名覆盖文件里的配置。参数用空格分隔，环境变量一行一个 KEY=VALUE。

提交 CLI

Commit / PR 使用的命令行。

TAPD

仅任务关联 TAPD 单且开启后，才走回填。密钥会写入项目配置，请按仓库规范处理。

E2E

默认不要写死业务环境地址；可用环境变量名。
